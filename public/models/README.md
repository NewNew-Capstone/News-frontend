# Runtime 3D Models

Put local GLB files in this folder using the exact filenames below. GLB files are ignored by Git, so share them separately with teammates.

| Usage | Required filename | Notes |
| --- | --- | --- |
| United States node in country comparison graph | `us-presenter.glb` | Meshy GLB model used instead of the US sphere node. |
| China node in country comparison graph | `china-presenter.glb` | Meshy GLB model used instead of the China sphere node. |
| Background object in country comparison graph | `china-congress-background.glb` | Low-opacity 3D model placed behind the comparison nodes. |
| United States recommendation stage | `us-white-house-stage.glb` | Small White House GLB shown behind each US recommendation preview. |
